# Material and Pricing Data Analytics Project

This Data Analytics for Artificial Intelligence project is organised into two final parts:

- **Part 1:** Contract cost prediction using cleaned English TED procurement data.
- **Part 2:** Material similarity, price-proxy matching, cost-effectiveness analysis and TED case-study demonstrations.

The current workflow no longer uses the older TED-material mapping notebooks as part of the final Part 2 pipeline.

### Part 2 — Materials and Cost-Effectiveness

Use the following notebooks for the final Part 2 workflow:

1. [`materials_project_cleaning.ipynb`](notebooks/materials_project_cleaning.ipynb)
2. [`world_bank_cost_preparation.ipynb`](notebooks/world_bank_cost_preparation.ipynb)
3. [`materials_clustering_analysis.ipynb`](notebooks/materials_clustering_analysis.ipynb)
4. [`materials_price_matching.ipynb`](notebooks/materials_price_matching.ipynb)
5. [`materials_cost_effectiveness_analysis.ipynb`](notebooks/materials_cost_effectiveness_analysis.ipynb)
6. [`ted_material_case_studies.ipynb`](notebooks/ted_material_case_studies.ipynb)

Part 2 operates as a staged decision-support pipeline:

1. Cluster materials into technically similar groups.
2. Match suitable price proxies to the material groups where reasonable.
3. Classify material costs within each technically similar cluster.
4. Identify potentially lower-cost candidate alternatives.
5. Demonstrate the approach using manually selected TED procurement case studies.

Price matching uses transparent proxy logic rather than exact market prices for every scientific material. The outputs are intended to support human interpretation and further investigation.

## Important Notes

- The project uses the English TED dataset for the final TED case-study stage.
- Part 2 should be described as an interpretable decision-support pipeline rather than a fully automated material recommendation system.
- Price matching uses transparent price proxies and does not claim to provide exact market prices for every material.
- Candidate alternatives are identified within technically similar material groups.
- All suggested alternatives require expert assessment before practical use.
- The case studies demonstrate how the pipeline can identify technically similar and potentially lower-cost material options.
